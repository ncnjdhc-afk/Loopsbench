# API Reference

This reference is generated from the `loopsbench` Python package with mkdocstrings. It covers the modules most users need when scripting evaluations, loading datasets, resolving task images, and integrating custom agents.

## Public Surfaces

- [CLI](cli.md): Typer command modules for tasks and runs.
- [Harness](harness.md): run metadata and benchmark result models.
- [Tasks and Datasets](tasks.md): dataset filtering, task metadata, and trial path helpers.
- [Agents](agents.md): built-in agent names, agent factory, and base class integration point.
- [Configuration](config.md): YAML run files, model runtime files, and Docker image strategy helpers.

For command-line examples, start with the [Quick Start](../quickstart.md) and [Running Benchmarks](../guides/running.md) guides.
