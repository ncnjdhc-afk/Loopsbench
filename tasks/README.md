# Tasks

The `tasks/` directory is the source of truth for LoopsBench benchmark tasks.

- `tasks/_template/` is the checked-in starting point for new contributions.
- `tasks/task_tcp_course_stack/` is the example multi-unit task referenced by the public contribution docs.

New tasks should be proposed through the GitHub issue form first, then implemented in a pull request that adds or updates a single `tasks/task_<id>/` directory.
